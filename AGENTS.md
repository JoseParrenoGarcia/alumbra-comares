# Alumbra Comares Agents Guide

## Why

This repository exists to help us design and build the first website for **Alumbra Comares** in a way that is easy to review, easy to change, and grounded in real stakeholder feedback.

The site is intentionally a lightweight first version. It should help the team react to structure, tone, visuals, and content before a more production-oriented rebuild.

## What

Agents working in this repository should optimize for:

- clear documentation before overbuilding
- reviewable increments
- simple static implementation
- content structures that can evolve
- faithful use of approved source material and explicit placeholders where needed

Stable project premises:

- official name: `Alumbra Comares`
- the project begins as a static `HTML + CSS + JavaScript` site
- content should be structured with future multilingual support in mind
- Spanish source material and placeholders are acceptable during early iterations
- implementation should stay lightweight until the product direction is validated

## How We Work Together

- Start from the PRD before making product or scope decisions.
- Treat image references as inspiration and draft source material unless explicitly confirmed.
- Keep unknowns visible with placeholders instead of inventing certainty.
- Put dynamic planning, delivery phases, open questions, and future tasks in the PRD or implementation docs, not here.
- Prefer simple solutions that are easy for future agents to understand and extend.
- When new decisions are made, update the most specific document that owns that topic.

## Document Ownership

Keep this file stable and lightweight. It should describe:

- why the repository exists
- what the project is at a high level
- how agents should collaborate
- where to find deeper context

Do not use this file for:

- v0 task lists
- delivery phases
- open questions
- research tracks
- discovery notes
- temporary implementation decisions

Those belong in the PRD or future docs under `docs/`.
