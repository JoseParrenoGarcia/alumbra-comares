# M17.2 — `/como-trabajamos` Standalone Page + Nav Switch

## Goal

Split the How We Work / Safety surface to its own page (`/como-trabajamos.html`). Homepage keeps a 3-block summary with a "leer más" link. Switch the full site navigation from anchor links to page links — all at once in this PR.

This is the second phase of the hybrid IA migration. Cómo Trabajamos second because: content is already mature (6 blocks from M17B), it directly addresses the highest trust gaps (C17 safety/transfer, C6 public-system relationship), and it serves personas P7, P8, P9, P12, P13. The nav switch happens here because once two detail pages exist the nav inconsistency becomes visible to users.

## Dependencies

- M17.1 complete

## PR Scope

- New `como-trabajamos.html` — top-level page scaffold. Loads all How We Work blocks from `content/how-we-work.json`.
- `js/content-loader.js` — extended for per-page how-we-work context: full 6 blocks on `/como-trabajamos.html`, 3-block summary on homepage
- `<title>`, meta description, og tags for `como-trabajamos.html`
- Homepage `sections/como-trabajamos.html` — becomes 3-block summary with "leer más →" link to `/como-trabajamos.html`
- **Nav switch (all at once):** Update `index.html` nav — both desktop nav and mobile hamburger overlay — from anchor links to page links:
  - Servicios → `/servicios.html` (page doesn't exist yet; link lands on homepage until M17.3)
  - Cómo Trabajamos → `/como-trabajamos.html`
  - FAQ → `/faq.html`
  - Recursos → `/recursos.html` (page doesn't exist yet; link lands on homepage until M17.4)
  - Contacto → `/#contacto` (stays as anchor — contact form stays on homepage)
- Internal cross-links: `como-trabajamos.html` → `/#contacto`; `faq.html` FAQ item faq-07 → `/como-trabajamos.html#safety` anchor
