# M20 — SEO Foundations and Metadata System

## Goal

Add right-sized SEO foundations: page metadata, social sharing metadata, structured data where appropriate, and a JSON-driven pattern for maintaining SEO fields without editing HTML directly.

## Recommended Delivery Mode

- Lead: Codex Sonnet or stronger
- Research support: human-run keyword prompt with results pasted back before implementation
- Haiku should not make the final SEO decisions on its own

## Dependencies

- M17 complete
- M18 and M19 recommended

## PR Scope

- `content/site.json`
- `index.html`
- Any shared JS needed to hydrate metadata from JSON
- Optional updates to legal or additional pages only if they need basic metadata parity

## Tasks

- [ ] Research keywords and phrasing relevant to:
  matrona Valencia, partera Valencia, embarazo, posparto, lactancia, and related local intent
- [ ] Define the SEO fields to live in `content/site.json`
- [ ] Add core tags:
  `title`, `meta description`, canonical, Open Graph, and basic Twitter/X sharing metadata
- [ ] Add structured data only if it is accurate and low-risk; do not invent organization facts
- [ ] Ensure the content editor can update core SEO fields without touching raw HTML
- [ ] Keep the implementation simple enough for a static site

## Human Research Prompt

```text
Help me define lightweight SEO foundations for a small independent midwife collective website in Valencia, Spain.

Please provide:
1. Likely Spanish search intents and keyword clusters around:
   matrona Valencia, partera Valencia, embarazo, parto, posparto, lactancia, acompañamiento
2. Which keywords seem high intent versus generic
3. Recommendations for homepage title tag and meta description options in Spanish
4. Whether a simple static site like this should add JSON-LD, and if so, which low-risk schema types are appropriate
5. SEO pitfalls to avoid for a small practice website

Keep the advice practical and conservative. Distinguish between facts, keyword suggestions, and your interpretation.
```

## Definition of Done

- Metadata is present and maintainable from JSON
- The chosen keywords and copy are documented
- Structured data, if added, is minimal and factually defensible
