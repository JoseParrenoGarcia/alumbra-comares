# M23 — Cookie Notice Audit and Rewrite

## Goal

Audit the deployed site’s actual cookie behavior and rewrite `cookies.html` so it says no more and no less than what the site really does.

## Recommended Delivery Mode

- Lead: human-led browser audit plus Codex Sonnet rewrite
- Not Haiku-led: this requires real-environment verification and risk judgment

## Dependencies

- M12 complete
- M16 complete if a new chat channel is added
- M20 recommended

## PR Scope

- `cookies.html`
- `content/footer.json` only if legal link labels need revision
- Optional short audit note in `docs/research/m23-cookie-audit.md`

## Tasks

- [ ] Audit the live deployed site for actual cookies, storage, and third-party requests
- [ ] Check at minimum:
  fonts, Formspree, embedded assets, chat links, and any analytics or social embeds
- [ ] Rewrite the cookie language in plain Spanish to match reality
- [ ] If the site truly uses no non-essential cookies, say so clearly and simply
- [ ] Avoid overclaiming compliance features that do not exist
- [ ] Avoid under-describing third-party behavior if it is actually present

## Human Audit Prompt

```text
I need help auditing the cookie posture of a very small static website.

The site may use:
- static HTML/CSS/JS
- Google Fonts
- Formspree
- basic external links
- possibly WhatsApp or Telegram links later

Please help me reason about:
1. Which of these typically set cookies or trigger third-party requests
2. What needs to be disclosed in a simple Spanish cookie notice
3. What would be overkill for a no-analytics, no-login, no-ads site
4. A conservative draft in plain Spanish

Distinguish between confirmed behavior and assumptions. I will validate the actual network behavior separately.
```

## Definition of Done

- `cookies.html` matches the site’s real deployed behavior
- The language is simpler and more honest than the current draft
- Any remaining uncertainty is documented instead of hand-waved

## Open Questions

- Will the production site later add analytics, embeds, or consent tooling?
