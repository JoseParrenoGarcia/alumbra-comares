# M32 — Mobile UX Pass: Section Sizing and Carousels

## Goal

Address two known mobile UX problems: sections that are too tall on small screens, and long horizontal card lists (testimonials, events) that do not work well in a single-column layout. The fix is a focused mobile-first audit and two targeted carousel implementations.

## Recommended Delivery Mode

- Lead: Codex Sonnet or equivalent — requires layout judgment alongside CSS edits
- Review: human check on a real mobile device before merge

## Dependencies

- M27 (accessibility audit) recommended before or alongside — carousel implementation must be keyboard-navigable and screen-reader friendly
- No hard blocking dependency; can run earlier if the mobile experience is a priority

## PR Scope

- `css/` — section padding/height fixes for mobile breakpoints
- `sections/testimonios.html` and `sections/eventos.html` — carousel markup
- `js/` — minimal carousel logic (scroll-snap or lightweight JS, no heavy library)
- No content JSON changes

## Tasks

### Section sizing
- [ ] Audit every section on a 375px viewport
- [ ] Reduce top/bottom padding on sections that feel disproportionately tall on mobile
- [ ] Ensure hero text and CTAs are visible without scrolling on a standard phone

### Testimonials carousel
- [ ] Convert the testimonials card row into a horizontal scroll carousel on mobile
- [ ] Use CSS scroll-snap as the primary mechanism; JS dots/arrows are optional enhancement
- [ ] Ensure cards are the right width on mobile (full or near-full width per card)
- [ ] Add visible scroll indicator (dots or count) so users know more cards exist

### Events carousel
- [ ] Apply the same carousel treatment to the events cards on mobile
- [ ] Desktop layout remains unchanged (grid or row)

### Accessibility
- [ ] Carousels must be navigable by keyboard (arrow keys or tab + enter)
- [ ] Add `aria-label` to carousel regions and navigation controls
- [ ] Respect `prefers-reduced-motion` — disable auto-scroll if present

## Definition of Done

- No section feels oversized on a 375px viewport
- Testimonials and events scroll horizontally on mobile with visible position indicators
- Desktop layout is unchanged
- Passes a manual keyboard navigation check
- Passes a manual check on both iOS Safari and Android Chrome

## Open Questions

- Should the carousel be touch-swipeable only, or should arrow buttons also appear on mobile?
- Is there a preference for CSS-only scroll-snap vs a small JS enhancement?
