# M19 — Resources Library / Blog

## Goal

Create a lightweight structure for recommended resources such as books, podcasts, associations, and useful links, with room to grow into a simple blog later if desired.

## Recommended Delivery Mode

- Lead: Codex Sonnet for content modeling and implementation guidance
- Build: Haiku pass is acceptable once the schema and IA target are explicit

## Dependencies

- M17 complete

## PR Scope

- `content/resources.json`
- A homepage section or dedicated page following the M17 recommendation
- Supporting CSS and minimal JS as needed
- `content/site.json` only if nav or SEO labels must be updated

## Tasks

- [ ] Define a content model that supports at least:
  category, title, type, description, link, author/source, and placeholder state
- [ ] Decide whether v1 of this milestone is:
  a curated resources library only, not an authored blog
- [ ] Populate a small starter set with clear placeholders if final recommendations are not yet approved
- [ ] Design for growth:
  the schema should not block a future article or post type
- [ ] Avoid adding a CMS or complex publishing workflow

## Definition of Done

- The project has a clear resources surface that fits the chosen IA
- Content remains JSON-driven
- The structure can later expand into a blog without a full rewrite

## Open Questions

- Should founder-authored reflections be part of this milestone, or only external recommendations?
