# M17.4 — `/recursos` Standalone Page

## Goal

Split the resources library to its own page (`/recursos.html`). Homepage keeps a 3-item summary with a "ver biblioteca completa" link. The brochure download CTA stays on the homepage only — it is not part of the resources library page.

## Dependencies

- M17.3 complete

## PR Scope

- New `recursos.html` — top-level page scaffold. Loads all resource items from `content/resources.json`.
- `js/content-loader.js` — extended for per-page resources context: full list with category grouping on `/recursos.html`, 3-item summary on homepage
- Category grouping on `recursos.html`: Libros / Asociaciones / Podcasts / Recursos Online (driven by existing `category` field in `content/resources.json`)
- `<title>`, meta description, og tags for `recursos.html`
- Homepage `sections/recursos.html` — becomes 3-item summary with "ver biblioteca completa →" link; brochure download CTA stays in this section on the homepage
- Internal cross-links: `recursos.html` → `/servicios.html` and `/faq.html` where relevant (e.g. a Cochrane resource links to `/servicios.html#atencion-parto`)
