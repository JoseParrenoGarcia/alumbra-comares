# M16A — WhatsApp Contact Implementation

## Goal

Add a WhatsApp contact entry point to the site following the recommendation produced in M16. The benchmark research (M13) identifies WhatsApp Business as the primary low-friction contact channel for families in Spain.

## Recommended Delivery Mode

- Lead: Haiku build pass is acceptable — changes are small and well-specified
- Review: human check that the button placement and copy feel warm, not transactional

## Dependencies

- M16 complete and WhatsApp channel approved in the research output
- M15 recommended first so CTA copy aligns with service positioning

## PR Scope

- `content/contact.json` — add WhatsApp channel entry
- `sections/contacto.html` — add WhatsApp button/link alongside existing channels
- `css/` — minor button style only if the existing contact channel pattern does not cover it

## Tasks

- [ ] Read `docs/research/m16-whatsapp-telegram-review.md` for approved link format and recommended copy
- [ ] Add WhatsApp channel object to `content/contact.json`:
  label, icon reference, link, and any display note
- [ ] Add WhatsApp button to the contact section using the same visual pattern as phone/email channels
- [ ] Use `https://wa.me/` link format (or whatever M16 specifies)
- [ ] Do not add chat widgets, pop-ups, or floating buttons — keep it as a static contact channel entry
- [ ] Confirm the link opens correctly on both desktop and mobile before closing

## Definition of Done

- WhatsApp appears as a contact channel alongside phone, email, and Instagram
- The link format matches the M16 recommendation exactly
- No new visual patterns are introduced — same icon + label style as existing channels
- Tested on mobile (where WhatsApp is most likely to be tapped)
