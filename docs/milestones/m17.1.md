# M17.1 — `/faq` Standalone Page

## Goal

Split the FAQ surface from a homepage section to its own page (`/faq.html`) with full FAQ schema markup. The homepage keeps a 5-item summary block with a "ver todas las preguntas" link.

This is the first phase of the hybrid IA migration decided in M17. FAQ first because: content is already mature (9 items from M17A), structural change is minimal, and FAQ schema markup gives the highest SEO leverage per effort.

## Dependencies

- M17 complete ✓

## PR Scope

- New `faq.html` — top-level page scaffold (not a section partial). Loads all FAQ items from `content/faq.json`.
- `js/content-loader.js` — extended to detect page context: full FAQ list on `/faq.html`, 5-item summary on homepage
- FAQ schema JSON-LD (`@type: FAQPage`) added to `faq.html`
- `<title>`, meta description, og:title, og:description, og:url tags for `faq.html`
- Homepage `sections/faq.html` — becomes summary-only: top 5 items + "ver todas las preguntas →" link to `/faq.html`
- No nav change in this PR — nav switches in M17.2
