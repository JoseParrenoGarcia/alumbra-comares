# M15 — Services Content Review and Rewrite

> **Status: superseded by M17.3.** The services content rewrite has been merged into M17.3
> (`docs/milestones/m17.3.md`), which combines the `/servicios` page split and the content
> rewrite as a single PR. This file is preserved for reference only.

## Goal

Improve the clarity of the services copy so a family can quickly understand what each service is, who it is for, and what kind of support it includes.

## Recommended Delivery Mode

- Lead: Codex Sonnet or equivalent strong writing-capable coding model
- Review: human approval on tone and factual accuracy
- Haiku can assist with mechanical JSON edits only after the revised copy is approved

## Dependencies

- M13 and M14 recommended

## PR Scope

- `content/services.json`
- `content/site.json` if section labels or metadata need updates
- Optional small markup updates in `sections/servicios.html` or `js/content-loader.js` only if the new content structure requires them

## Tasks

- [ ] Audit every current service entry for ambiguity, overlap, and missing context
- [ ] Rewrite each service description in Spanish using plain, warm, non-clinical language
- [ ] Add structured subfields where useful:
  short summary, who it is for, what it may include, and placeholder pricing note
- [ ] Keep every factual claim anchored in known source material or an explicit placeholder
- [ ] Do not invent medical promises, outcomes, certifications, or coverage terms
- [ ] If the current card layout cannot support the clearer structure, propose the minimum content-model change needed

## Definition of Done

- `content/services.json` is easier to understand without becoming bloated
- Each service feels distinct from the others
- Placeholder language remains visible wherever specifics are still missing
- Any schema change is documented in the milestone PR notes

## Open Questions

- Should services stay concise on the homepage with deeper detail elsewhere later?
- Is pricing better kept as a soft placeholder until the founders confirm it?
