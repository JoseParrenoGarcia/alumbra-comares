# M16 — WhatsApp / Telegram Feasibility Review

## Goal

Decide whether Alumbra Comares should add WhatsApp, Telegram, both, or neither as direct contact channels, and document the exact implementation path if approved.

## Recommended Delivery Mode

- Lead: human-led external research plus Codex Sonnet synthesis
- Not Haiku-led: this requires current platform-policy checks and a product recommendation, not just code edits

## Dependencies

- M12 complete
- M15 recommended first so contact CTA wording matches service positioning

## PR Scope

- `docs/research/m16-whatsapp-telegram-review.md`
- `content/contact.json` only if a channel is approved and messaging is ready
- Optional follow-up implementation milestone can be spun out if needed

## Tasks

- [ ] Research current free or low-cost options for:
  WhatsApp Business and Telegram contact entry points
- [ ] Determine whether direct chat links can be opened safely from the website
- [ ] Compare user expectation fit for the target audience in Spain
- [ ] Note operational implications:
  phone number visibility, working-hours expectations, response burden, and privacy implications
- [ ] End with a recommendation:
  add now, defer, or avoid
- [ ] If approved, specify the exact link format and content updates required

## Human Research Prompt

```text
Help me evaluate whether a small independent midwife collective in Valencia, Spain should add WhatsApp Business and/or Telegram contact options to its website.

Please research current, real-world constraints and answer:
1. Can a small practice create and use a free WhatsApp Business account?
2. Can a website open a direct WhatsApp chat reliably? What is the preferred link format?
3. Can a website open a direct Telegram chat or channel reliably? What is the preferred link format?
4. What are the setup requirements, ongoing expectations, and tradeoffs for each?
5. Which option is more natural and trusted for families in Spain?
6. What privacy or legal considerations should a small practice keep in mind?
7. Final recommendation: WhatsApp, Telegram, both, or neither

Please cite current sources and distinguish facts from recommendations.
```

## Definition of Done

- The team has a clear recommendation with tradeoffs
- If a channel is approved, implementation details are explicit enough for a small coding agent to add later
- If no channel is approved, the reasons are documented

## Open Questions

- Is the team comfortable exposing a dedicated phone number publicly?
- Who would own response time expectations if chat is enabled?
