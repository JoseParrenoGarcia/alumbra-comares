# M18 — Education and Credentials Section

## Goal

Add a trust-building section or page that explains the team’s formal education, qualifications, and training without slipping into corporate or boastful language.

## Recommended Delivery Mode

- Lead: Haiku build pass is acceptable if the IA decision from M17 is already clear
- Review: Sonnet review pass for tone, schema quality, and scope discipline

## Dependencies

- M17 complete

## PR Scope

- `content/education.json`
- One of:
  `sections/formacion.html` or a new dedicated page if M17 recommends it
- Supporting CSS and minimal JS only if required by the chosen layout
- `content/site.json` and nav/footer content only if a new entry is needed

## Tasks

- [ ] Define the education content schema before writing markup
- [ ] Support entries such as:
  degree, master, certification, course, training, affiliation, year, and placeholder flags
- [ ] Populate only confirmed items; use explicit placeholders where the source material is incomplete
- [ ] Present the material in a warm, readable structure:
  grouped list, timeline, or cards
- [ ] Keep it confidence-building, not exhaustive for its own sake
- [ ] Follow the IA decision from M17 exactly; do not invent new nav structure

## Definition of Done

- The education material is structurally present and easy to skim
- Unknowns remain visible as placeholders
- The result increases trust without feeling bureaucratic

## Open Questions

- Is there already confirmed source material for formal qualifications, or will founders need to supply more?
