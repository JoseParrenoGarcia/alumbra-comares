# M12 — GitHub Pages Deployment

## Goal

Deploy the site to GitHub Pages and verify it is accessible, functional, and visually correct at a public URL. This is the final milestone before founder review begins.

## PR Scope

- `.github/` or repository settings for GitHub Pages configuration
- Final asset and path checks
- `README.md` update with the live URL

## Tasks

- [ ] Verify all asset paths are relative (no absolute local paths)
- [ ] Verify all `href` and `src` attributes resolve correctly on GitHub Pages
- [ ] Verify Google Fonts load (requires internet access — check CSP if needed)
- [ ] Set up GitHub Pages: deploy from `main` branch, root `/`
- [ ] Confirm Formspree endpoint is set (or clearly marked as placeholder)
- [ ] Test live URL on mobile (iOS Safari and Android Chrome)
- [ ] Test live URL on desktop (Chrome and Firefox)
- [ ] Check all navigation anchors work at the live URL
- [ ] Check privacy and cookie page links in footer
- [ ] Update `README.md` with live URL
- [ ] Remove any dev artifacts or commented test code

## Pre-Deploy Checklist

- [ ] No hardcoded `localhost` or local file paths
- [ ] All JSON content files are present
- [ ] All CSS imports resolve
- [ ] No console errors on load
- [ ] `<meta charset>`, `<meta name="viewport">`, and `<title>` set correctly
- [ ] Formspree endpoint confirmed or clearly marked placeholder

## Definition of Done

- Site is live at a public GitHub Pages URL
- Site is viewable on phone and desktop without errors
- Founders can be sent the URL for review
- README contains the live URL
