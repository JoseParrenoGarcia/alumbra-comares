# M13 — External Website Benchmark Audit

## Goal

Study comparable midwifery, birth support, and independent care websites so later product decisions are based on real patterns instead of guesswork.

## Recommended Delivery Mode

- Lead: human-led research using 2–3 external models plus Codex Sonnet synthesis
- Not Haiku-led: this milestone depends on live web research, judgment calls, and comparison quality

## Dependencies

- M12 complete

## PR Scope

- `docs/research/m13-external-benchmark.md` — benchmark table and synthesis
- `docs/PRD.md` — update only if a clear product-level recommendation emerges
- `docs/plan.md` — optional status update after completion

## Tasks

- [ ] Identify 8–12 relevant websites:
  independent midwives, birth centers, doula collectives, or similarly warm community-led care practices
- [ ] Prioritize Spain first, then broader Europe, then a few strong international references
- [ ] Capture for each site:
  homepage structure, nav pattern, trust signals, service presentation, contact pattern, legal footer pattern, and overall tone
- [ ] Note what feels strong, weak, too corporate, too clinical, or too vague
- [ ] Produce a short "borrow / avoid / not relevant" summary for Alumbra Comares
- [ ] Do not copy layouts or copy literally; this is a pattern audit, not a cloning exercise

## Human Research Prompt

Use this prompt in ChatGPT, Claude, Grok, or similar. Ask for links in the response, then paste the results back into the repo workstream before drafting the final benchmark doc.

```text
You are helping audit websites for Alumbra Comares, a warm Mediterranean-style independent midwife collective in Valencia, Spain.

Find 8–12 relevant live websites for:
- independent midwives
- small midwifery practices
- birth centers
- doula or perinatal collectives with a similarly human, non-corporate positioning

Prioritize Spain first, then Europe, then a few strong international examples.

For each example, provide:
1. URL
2. Country
3. Type of practice
4. Information architecture pattern: single page, multi-page, hybrid
5. How they present services
6. How they build trust: credentials, testimonials, philosophy, affiliations, team bios, FAQs, pricing transparency
7. Contact pattern: form, phone, WhatsApp, booking tool, Instagram, etc.
8. Tone notes: warm, clinical, spiritual, community-led, premium, etc.
9. What Alumbra Comares should borrow
10. What Alumbra Comares should avoid

End with:
- top 5 recurring best practices
- top 5 pitfalls
- recommendation for a small first website in Spain
```

## Definition of Done

- A reviewer can read one document and understand the current market patterns
- At least 8 live examples are documented with links
- The output includes concrete recommendations for later milestones

## Open Questions

- Should Spain-only comparables be weighted more heavily than global inspiration?
- Do we want a few adjacent references from yoga / lactation / women’s health collectives, or strictly midwifery?
