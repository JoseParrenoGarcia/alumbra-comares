# M3 — HTML/CSS Scaffold: Design System and Layout Shell

## Goal

Build the base HTML page structure, CSS design system (tokens, typography, spacing, utilities), and empty section shells. No real content is wired in yet — this milestone proves the design language works end-to-end.

## PR Scope

- `index.html` — page shell with empty section elements and correct `id` anchors
- `css/tokens.css` — all CSS custom properties from `docs/style.md`
- `css/typography.css` — type scale, font imports, heading/body/quote styles
- `css/layout.css` — grid system, section padding, max-width wrapper
- `css/utilities.css` — minimal utility classes (reveal animation, botanical accent placement)
- `css/main.css` — imports all partials in order

## Reference

[`docs/style.md`](style.md) is the sole design source of truth for this milestone.

## Definition of Done

- Page renders without errors in Chrome and Firefox
- CSS tokens match `docs/style.md` exactly
- All section anchors exist in HTML
- Smooth scroll between sections works
- Scroll reveal initialises on page load
- Mobile and desktop breakpoints respond correctly
