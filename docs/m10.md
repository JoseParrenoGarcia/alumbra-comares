# M10 — Testimonials and Brochure Placeholders

## Goal

Add the testimonials and downloadable brochure placeholder blocks. These sections must be structurally present and visually coherent even with no real content — they signal future capability without looking broken.

## PR Scope

- `index.html` — populated testimonials and brochure placeholder sections
- `css/testimonials.css`
- `css/brochure.css`

## Tasks

### Testimonials

- [ ] Section with 2–3 placeholder testimonial cards
- [ ] Each card: quote text, first name, role tag (e.g. "Mamá primeriza, Valencia")
- [ ] Placeholder text should feel warm and plausible, clearly marked as draft
- [ ] Layout: card row on desktop, stacked on mobile
- [ ] Scroll-reveal on cards

### Brochure / Resources

- [ ] Section with a single download CTA card
- [ ] Icon, title, short description, download button
- [ ] Download button links to `#` placeholder until a real PDF exists
- [ ] Subtle note: "Próximamente" or "disponible pronto" if no asset is ready

## Definition of Done

- Both sections render without broken states at all breakpoints
- Placeholder content is clearly draft (no real patient data, no invented specifics)
- Download CTA is present and styled correctly
- Sections do not look visually empty or abandoned

## Open Questions

- Are any real testimonials available to use now (anonymised)?
- Is a PDF brochure being prepared, and when might it be ready?
