## i18n Convention

Each string field that will need translation should use the following structure:

```json
{
  "es": "Texto en español",
  "en": "Text in English",
  "ca": null
}
```

Fields that are not translated yet should use `null` for missing languages.

## Definition of Done

- All JSON files exist and are valid
- Real content from reference material is used where available
- Placeholders are clearly marked with a `"__PLACEHOLDER__"` prefix or a `placeholder: true` flag
- No HTML depends on these files yet — they are purely a content artifact
